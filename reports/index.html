目录维护说明

目录职责
reports/按产品、B14、内存诊断和工具分类的 HTML 与同名结构化报告。
data/统一计划、报告索引、首页派生数据与历史摘要；不以新索引覆盖原始结论。
evidence/原始证据或指纹一致副本；保留历史输入边界。
inputs/限定工具门的直接输入快照，仅作追溯与校验。
audit/既有分类、迁移与来源可用性审计；不属于重复产品验收项。
scripts/生成首页和目录并进行静态校验；本次不执行产品或长稳。

新报告放入对应分类目录，通常将同名 JSON 与 HTML 相邻；历史指标页复用已登记的 data/b14-historical-metrics.json。执行 node scripts/assemble.mjs 更新首页和目录，再执行 node scripts/validate.mjs 核对文档。报告中的外部本机证据链接依赖原机器路径，不保证轻量副本可访问。
